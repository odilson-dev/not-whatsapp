## Replace with real captures (recommended)

For a stronger portfolio impression, swap the SVGs with real PNG screenshots:

1. Run `pnpm dev` and `npx convex dev`
2. Sign in, create a few chats and a group
3. Capture at ~1200×675 (16:9) or similar
4. Save as `chat-list.png`, `group-chat.png`, `admin.png`
5. Update image paths in the root `README.md`
